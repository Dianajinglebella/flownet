# Flownet

**Your best work deserves a second income.**

Flownet turns what creators already post on Instagram and TikTok into work that people can find and AI can cite, and pays creators when it is used.

This repository holds the Flownet website and clickable app prototype: one self-contained `index.html` (fonts embedded, no build step, no external requests).

## Run it

Open `index.html` in any browser.

## Host it

Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root). The site will be live at `https://<your-username>.github.io/flownet-website/`.

## Notes

- Posts, people and numbers in the prototype are concept examples.
- The live "write a sentence" compiler only works when the page is opened inside claude.ai; elsewhere it shows built-in examples.
